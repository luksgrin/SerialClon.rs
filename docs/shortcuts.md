# Keyboard shortcuts

`⌘` on macOS is `Ctrl` on Windows and Linux; `⌥` is `Alt`. The table is the original's (User
Manual §III) with the entries added in 2.x; new in SerialClon are marked.

## File

| Shortcut | Command |
|---|---|
| ⌘N | New |
| ⇧⌘N | New Degenerate DNA |
| ⌘O | Open… |
| ⌘W | Close |
| ⌥⌘W | Close All |
| ⌘S | Save |
| ⇧⌘S | Save As… (also Alt-click Save) |
| ⌘P | Print… (maps) |
| ⌘, | Preferences… |
| ⌘Q | Quit |

## Edit

| Shortcut | Command |
|---|---|
| ⌘Z / ⌘Y | Undo / Redo (five levels) |
| ⌘A | Select All |
| ⌘X / ⌘C / ⌘V | Cut / Copy / Paste |
| ⌘K | Copy as Fasta |
| ⇧⌘K | Copy Non Formatted |
| ⇧⌘J | Copy All Sequences To Multifasta |
| ⌘F | Find… |
| ⌘R | Find ORF |

## Sequence

| Shortcut | Command |
|---|---|

## Inside windows

| Key | Where | Effect |
|---|---|---|
| Space | Graphic Map | Toggle CW / CCW (or sense / antisense) of the selection |
| A | Graphic Map (linear) | Select the whole insert |
| Delete, Escape | Graphic Map | Cancel the selection |
| S | Features tab | Show / hide Features |
| Arrows, Home, End, Page Up/Down | Sequence field | Move the insertion point; with Shift, extend the selection |
| Type letters | enzyme lists | Jump to the enzyme |

## The Alt modifier

| Alt + | Effect |
|---|---|
| Save button | Save As… |
| **−** (Features) | Delete without confirmation — the button turns red |
| Show checkbox (Features) | Show or hide all |
| Import (Manage Features) | Export |
| Click on a map | Bring the parent Sequence Window to the front |
| Toolbar New / Save | New Degenerate DNA / Save As… |
